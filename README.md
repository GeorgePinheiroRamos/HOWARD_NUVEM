## Como estudar

Entre na pasta da aula, leia o README correspondente e execute os exemplos a partir das instruções daquela página. Os componentes compartilhados de Redis, modelo, REST, worker e gRPC estão separados por responsabilidade para facilitar a leitura e a execução.

## Critérios técnicos contemplados

A organização evidencia decomposição em serviços, comunicação REST/gRPC/mensageria, tratamento de falhas com tentativas e dead-letter, além de execução reproduzível com dependências e Docker Compose.
